# 歌词段落模板

把下面的标签和空行结构复制出去，换成用户的词。括号里的英文只是表演提示，不要写进要唱的句子。措辞由用户或共同创作决定，本文件不提供固定故事。

```text
[Verse 1: almost whispered self-talk; pause after every line; short endings]
（主歌一：最低音量，像自言自语，每行后留气口，尾音短收）

[Verse 2: first half almost spoken; then heavier and slower; brief lift; then quieter, leave space]
（主歌二：先近乎口白回忆，再沉下去；短暂提亮后收住）

[Chorus: ask gently; rest after each question; slight lift then short cutoff; last line almost breath]
（副歌：轻声但认真地问，每个问句后留空拍；最后一句几乎变成气声）

[Verse 3: tighter, conversational, clipped short endings; pause after hard lines]
（主歌三：稍紧一些，像说话，硬句后面停一下）

[Bridge: quiet confession, almost spoken, long pauses between lines]
（桥段：最安静的剖白，句与句之间拉长停顿）

[Final Chorus: softer, more space, letting go, not louder]
（末次副歌：比第一次副歌更软、更放开，不要更响）

[Outro: softest self-talk; last line very soft, short, nearly spoken]
（尾奏：最轻；最后一句又短又轻，不要唱满）
```

## 断句检查

写完后通读一遍：

- 每一行是否能一口气唱完，又不必把字挤在一起
- 是否误在「的 / 了 / 着 / 过 / 再 / 没有 / 立刻」后切断
- 需要悬住的句子是否用了「……」
- 段落标签是否都是英文，正文里是否误留了中文表演说明
- 容易读错的字是否加了简短拼音，如 `没(méi)收到`
