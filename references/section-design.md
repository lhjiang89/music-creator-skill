# 根据歌词做分段演唱设计

Styles 不能先写曲风形容词，再硬套到任何一首词上。要先读已经定稿的歌词，逐段找出情绪、场景、质感和调性，再压缩进 1000 字符。

## 怎么从歌词里找这四件事

对每一段只依据词里有的内容，不要添加词里没有的情节。

| 看什么 | 问自己 | 写成 Styles 时的方向 |
| --- | --- | --- |
| 情绪 | 这一段是在说、在问、在回忆、在对峙，还是在放手 | self-talk / spoken memory / soft questions / confession / letting go |
| 场景 | 词里出现的时间或空间，例如海边、日常相处、冲突之后 | 用很短的英文场景词点一下，不要写旁白 |
| 质感 | 该更像说话还是更像唱；人声该近还是远；伴奏疏还是密 | almost spoken, breathy, clipped endings, warm piano, airy guitar |
| 调性 / 音量 | 相对前后段，这里该更轻、更沉、稍抬，还是最轻 | lowest volume, brief lift not shouted, softer not louder |

典型的力度曲线（可按具体歌词调整，但必须有对比）：

1. Verse 1 往往最轻，像自言自语
2. Verse 2 先口白回忆，再沉下去，中间若有转机可短暂提亮，然后收住
3. Chorus 是认真地问，不是高潮喊唱；问句后留空拍；最沉的那一句可以接近气声
4. Verse 3 稍紧、稍口语，硬句后停
5. Bridge 全曲最安静的剖白，句间停顿更长
6. Final Chorus 比第一次副歌更软、更放开，不要更响
7. Outro 最轻，最后一句又短又轻，不要唱满

## 先写给用户看的中文说明（示例格式）

把各段写成短列表，方便用户改，而不要先丢出一整块英文：

```text
主歌一：开端的回忆，音量最低，像自言自语，尾音短收；钩子稍清晰，然后马上收回。
主歌二：前半近乎口白；写到难受时放低、放慢；短暂提亮后，失望的句子再安静下来。
副歌：轻轻地问，每个问句后留一拍；最后的收束接近气声，不要把副歌唱成高潮。
主歌三：稍紧的叙述，不要戏剧化，硬句后面停一下。
桥段：最轻的剖白，几乎是说话，句与句之间拉开。
末次副歌：同样的词，更软、更放手，不要更响。
尾奏：最轻；最后一句几乎不是完整地唱出来。
```

用户认可后，再把它译成歌词里的短英文标签，以及 Styles 里各一段的英文句子。

## 压缩到 1000 字符时的取舍

必留：参考唱法或人声气质、反平淡（含「同样轻也是平」）、换气和不要塞拍、分段各一句、反面约束。

可删：重复的形容词、过细的乐器清单、与歌词对不上的场景词。

交 Styles 时写明字符数，例如 `Styles 1000/1000`。
