# 在 Suno 上代为创作（Computer Use）

只有同时满足下面两点，才走这一页：

1. 当前会话里确认有 Computer Use / 浏览器或桌面控制能力
2. 用户已经确认歌词和 Styles，并明确同意由代理在 Suno 上代为操作

否则不要打开 Suno，不要尝试登录，把可粘贴文本和 [创作页链接](https://suno.com/create) 交给用户即可。

## 打开和登录

- 直接打开 https://suno.com/create
- 若已经登录，保持当前账号，不要退出或切换账号
- 若需要登录、验证码或人机验证，停下来请用户完成，不要擅自填写或猜测密码，也不要绕过登录墙
- 若出现升级、付费、购买积分或自动充值，停下来告诉用户。只有用户明确要求付费时才继续

## 填写表单

使用 **Custom / Advanced**，不要用一句简单描述直接出歌，除非用户只要草稿。

- 如有上次留下的 Cover / Remix、参考音频或旧歌词，先清空
- Lyrics：粘贴完整带标签歌词，确认读音提示还在，字符数不超过 5000
- Styles：只粘贴到风格栏，字符数不超过 1000
- Title、人声、Duration（未指定则 Auto）按已确认的成品填写
- 选择当前套餐下最好的正式模型，不要用 Mini
- 除非这一轮明确要用 Cover，否则必须是空白 Custom
- 全部在页面上核对后，只点一次 Create
- 等待两首完整歌曲生成结束，不要把 1 分钟未付费预览当成成品

## 下载和交付

- 付费套餐优先下载官方 WAV 和官方 MP3；不要为此额外付费或升级，除非用户要求
- 把两首的链接、时长和音频交给用户
- 核对应和播放条、文件完整性，见主技能里的「验收和交付」
- 结束后不要改动账号套餐设置

## 失败时

登录不了、页面报错、积分或下载被拦截时，停下来说明原因，并把同样的 Lyrics 和 Styles 交给用户，让他们自行在 Suno 里完成。不要反复尝试付费路径。
